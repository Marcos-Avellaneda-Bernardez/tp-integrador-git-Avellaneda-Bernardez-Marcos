# Manual Steering Servo motor

## Descripcion
Se busca una mayor comprencion de la placa ESP32-C3 con el framework Arduino a travez de un proyecto simple

## Objetivos
Se busca girar el cuerno de un servo en sentido horario o antiorario de un servo motor usando dos botones y encendiendo 2 leds, uno al precionar el boton izquierdo y el otro el boton derecho

## Estructura de repositorio
Consta de :
1) Dos directorios (uno para el codigo principal del proyecto y otra para definir los pines y constantes usadas configurar las librerias)

2) Un README.md 

3) ENTREGA.md nesesario para la entrega del proyecto

4) Una imagen png con el diagrama de las conexiones del circuito.
