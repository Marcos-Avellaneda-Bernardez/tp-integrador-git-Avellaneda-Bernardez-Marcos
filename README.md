# Manual Steering Servo motor

## Descripcion
Se busca una mayor comprencion de la placa ESP32-C3 con el framework Arduino a travez de un proyecto simple

## Objetivos
El sistema hace girar el cuerno de un servo en sentido horario o antiorario al usar uno de dos botones.Al precionar un boton se encende 1 leds y suena un sumbador 

## Estructura de repositorio
Consta de :
1) Un directorio que contiene los archivos con el codigo principal para el proyecto y una libreria para este proyecto

2) Un README.md 

3) ENTREGA.md nesesario para la entrega del proyecto
